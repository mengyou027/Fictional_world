# 第一章 种子

1858年春，雨晴过后的午时，树荫漏出了阳光，照亮了土泥地上的水面。

花子在泥路上奔跑，踏出了水花，来到了一条溪流旁。蹲下搅了搅水，对着倒影的自己笑了笑，就像一个天真无邪的小女孩。

她跑到溪流的大石头上，把木屐放在一旁坐了下来，晃着小腿望着眼前的树林，脸上一直露着微笑，乐此不疲。

她已经不止一次避开大人的视线，溜到这片林子里闲玩，这里安静的就像是她一个人的世界，时常还能听到鸟鸣，就像是为她独奏的乐章。

突然一阵风吹来，伴随着什么东西折断树枝，落在地上的声音。

花子穿上木屐，跳下石头，怀着好奇心慢慢走过去，仿佛是天真指引着她，抑制了恐惧。

看到一位少女倒在了溪流上，砸出了浅坑，她忽然起身，花子愣的后退了几步。

花子对那名少女说：“你…你是谁？”

她听懂了日语，缓缓起身道：“我？我是崩坏，一个异乡客。”

等她站起来后，花子看到了她完整的容貌，穿着不属于这个时代的服饰，一双深邃蓝色的眼睛，从黑到蓝的渐发，还有一双淡蓝色的手臂。

崩坏喊道：“喂，发什么呆呢？不搭理人的话，可是不礼貌的。”

花子回过神来，说道：“抱歉，我…我叫花子。”

“嗯～花子，好名字。”说完看了一眼周围，崩坏只感到了无趣，这对她来说是一个没有破坏价值的世界。

突然坏笑着，既然如此，不如找点乐子，刚才的女孩就不错，赐予她崩坏的力量，如果能活下去，我算她是一个合格的神职者。

崩坏转过身问：“花子，有没有兴趣带我四处走走？”

花子点了点头：“当然可以！那我带你去一个地方吧。”

崩坏跟在花子的后面，走的全是看不到人的小路，来到石台阶往上走，经过了一个又一个的鸟居。

花子不急道：“我们很快就到了，这个时候一般没人来的。”

神社的狐神吃着桃子哼着曲，坐在台阶晃着腿，看到了时常光顾神社的花子，半睁着眼像没了情绪，这孩子已经是好几次来偷吃我东西了。

花子拿了一个贡品寄给崩坏：“吃吧！”

崩坏笑了笑：“这是人家的贡品吧？”

“没事的，反正也不会有人知道是谁吃的，吃饱了我再带你去其他地方吧。”

崩坏看着台阶坐着的狐神，狐神睁大了眼睛，不会吧，难道她能看到我？！不可能，绝对不可能，她身上有一股特别的气息，难道是来自外界的真神？怎么办，还是当睁眼瞎吧！

花子扯了一下崩坏的衣服说：“你在看什么？”

崩坏摇摇头：“没什么，好奇而已。”

崩坏再回看，狐神早跑的没影了，算了，反正是一个没有神力的妖怪，不足挂齿。

花子擦了擦嘴，笑眯眯的说：“嘿呦，我吃好了，你吃好了，我们就去下一个地方吧！”

崩坏微微一笑：“当然。”

两人走了比较远的路，来到了一片樱花林，这对崩坏来说，已经是再平常不过的风景了，对她来说，没有什么比直面超新星来得壮观了。

花子一脸笑嘻嘻的看着她：“怎么样？平时很少看到呢，也就碰巧能看看了。”

崩坏叉着腰道：“哈？照你这么说，我来的还真是时候？”

“那当然！”

说着，二人走到树下坐着，一阵阵春风吹过，只有微微风噪，这一刻仿佛时间被放缓。

——春风如梦，虚归真。

崩坏看向花子，问：“花子，你有梦想吗？或者说以后会做什么？”

花子摇了摇头：“不知道……可能会一直在这里，我从来都没有这种想法，也不知道以后会在哪里。母亲说过外面很危险，只能在这里，哪也去不了。”

崩坏双手摸着她的脸：“现在是这样，以后可就说不定了，对你来说，只是时候未到。”

说着，崩坏亲吻了花子的额头，为她种下——来自崩坏的种子！

崩坏起身向前走了几步，说：“时候差不多了，我也该走了。”

花子还有些恋恋不舍：“那，我们什么时候才会再见？”

崩坏悬浮在空中，面对着花子：“这是连我都不确定的答案，但只要活下去，终会有见面的那一天。”

空中出现了一个虫洞，眨眼间崩坏随着虫洞一同消失，就像刮起了大风，没人知道这里发生了什么。

花子慌张地看着周围，她分不清这是一场幻觉还是梦，不安的情绪促使着心脏快速地跳动，一切都那么真实。

花子向家中狂奔，一刻也未停留，在房间内喘着大气，眼神逐渐模糊，直到失去意识。

兄长走进房门，发现花子倒在了地上，身体仍然在大口呼吸，抱起花子喊道：“喂！醒醒，花子！怎么回事！”

兄长奔出家门，拜托了母亲照看花子。

次日，花子缓缓睁开眼，眼泪湿润着模糊的眼线，用胳膊拭去眼泪，是她最熟悉的天花板。

兄长摸了下花子的额头：“身体感觉怎么样？有什么不舒服的地方吗？”

花子摇了摇头：“我这是怎么了？”

“你昨天回来后突然发了场高烧，我和母亲都要吓坏了，幸好没什么大病。”

说着，兄长突然发现花子的眼睛变成了深邃的蓝色，疑惑道：“你的眼睛以前是蓝色的吗？”

听着，花子回想起了昨天的事，但还是埋在心底，摇摇头道：“我不知道。”

花子有时会看着水面的倒影，她不知道以后这双眼睛会为她带来什么，但她知道，当下最最重要的就是活下去。

——初见深蓝之眼，崩坏！

# 第二章 飒

兄长的打铁声，回荡着整个屋子，花子无聊的坐在家门前，双手托着整个脸，小腿在眼前晃晃悠悠的。

自从今天开始，花子看得比往常更远，甚至能在白天看到隐隐约约的星星，对花子来说，如同梦境般的存在，眼见为实。

除此之外，没有感觉到其他的异常，甚至比以往更有活力，很少有疲惫的感觉。

目前对她来说还算正常，但还不知道以后会发生什么，这要是崩坏的全部，显然不太可能，花子很担心，但还是装着无事发生。

忽然一位男孩出现在发呆的花子面前，问：“你好，请问你坐在这儿在想什么？”

花子抬头看着面前，那英俊纯良的男孩，似乎只比自己大了一两岁，花子愣了一下，才回答：“你是谁？我想什么跟你没关系吧。”

“抱歉抱歉。”说着，做了个自我介绍：“我叫藤原飒，我和父亲来这里锻一把新刀，刚好注意到你，所以想跟你做个朋友。”

花子伸出了手，并说着：“啊，原来是这样吗？很高兴认识你，我叫花子，这家的女儿。”

飒刚握上手，脸颊微红，突然注意到花子的那双眼睛，说：“你的眼睛是蓝色的？好漂亮，为什么？”

花子摇了摇头：“不知道。”

飒又继续说道：“你的眼睛里一闪一闪的，像有一群星星一样，像一颗蓝宝石。”

花子害羞地抓着衣襟，小声道：“有那么好看吗？”

“当然，你的眼睛绝对是我见过的独一无二的。”

“谢谢你这么说，我还是第一次听到这样的话。”

几天后，飒又来到了花子家的铁匠铺，花子高兴地冲上去，问：“你怎么来了？”

飒解释道：“今天有空，来找你玩，毕竟你也算我第一个朋友。”

花子拉着他的手，手指嘘声道：“我带你去个好地方。”

说完就拉着他的手前往神社的路上，飒的脸颊微红，他从来都没想过会有女生这样拉着他，阳光照在她的身上，如同天使指引着他。

狐神躺在地板上，盯着房檐的风铃发呆，刚一侧身，她又来偷吃了，还带了一个男孩，真是奇怪，我的神社难道是什么食堂吗？这家伙怎么每次都来！

花子在神社面前停下，眼睛看着躺在那里的狐神，飒问她：“怎么了？你在看什么？”

花子看了一眼飒，又指着狐神：“你看不到她吗？”

狐神震惊了一声：“什么！？”

这次怎么看到我了？难道那天发生了什么吗？还是说，我的力量比明天更弱了？

飒摇了摇头：“我什么都没看到，怎么了？”

花子看着那边的狐神，手抵着胸口，难道自己出现幻觉了？

于是花子无视狐神，继续带着飒走进神社里面，拿了贡品就走了出去。

狐神看着盘子里只剩下了桃子，拿着啃了一口，可恶！都看到我了，怎么还吃啊！

次日凌晨，花子从半夜中醒来，对那位狐神愈发愈好奇，小心翼翼地开关门，从家中溜走。

他看着晚上的星星，似乎比白天还亮，还有许多以前看不到的远星，月光更亮，几乎照亮了周边的轮廓。

花子大气不喘地一路跑到了神社，大喊道：“你在吗！听到了就回我一句好不好！？”

狐神出现在身后：“喂，我说啊，你不用睡觉的吗？打扰别人休息可不礼貌啊！”

花子被吓了一跳，连忙道歉：“对不起，对不起！我不知道神还要休息。”

狐神摆了摆手：“算了算了，说回来，你找我有什么事？最好说点我不知道的。”

花子嗯了一声道：“我有时候走神，偶尔会进入一个神秘的地方，那里漆黑一片伸手不见五指，你知道怎么办吗？”

狐神边想边说道：“走神，进入一个神秘的地方？伸手不见五指，听起来有点像东方修仙者的神识，从零到有建立自己的世界，是一种提升修为的方法，或许你这个和那个差不多，不过是那个女人的权能的话，用途或许不一样。”

花子睁大了眼睛，看着狐神：“难道你有什么办法了吗！”

狐神摇摇头：“不知道呢。”

花子失落的低下头，狐神继续道：“不过没关系，我们可以试一试。”

花子看着她，问：“怎么试？”

“你可以试着把我拉入那个空间，或许我就能知道是什么情况了。”

花子闭着眼睛，不知道在使什么力，狐神制止道：“喂喂喂，你在闭着眼睛拉屎吗(*｀へ´*)？试着以手掌为参照物，大拇指与食指中间对着我，试着把我吸进去。”

花子照着狐神的说法做了，一瞬间她就不见了，花子慌张道：“哎？怎么不见了，别吓我啊。”

突然，内心中冒出了狐神的声音：“喊什么呢？我已经进来了，你试试找找睡神的感觉，看看能不能进来。”

说完，花子照着做，睁开眼后，面前变得一片漆黑：“我进来了，你在哪儿？我看不到你！”

狐神在手上生成了个悬空的火，照亮着两个人：“看来跟我想象的不一样，这分明就是个意识空间，按理来说，你可以在这里储存想要存的东西，我能感受到这里的时间流速与外面不一样。”

花子看着脚底，若有所思道：“原来我一直在漂浮，怪不得之前老有一种无力感，可是这里空荡荡的，没有落脚的地方。”

花子话音刚落狐神突然想到了什么：“空荡荡的？如果你能给我这里的管理权限的话，我或许可以在这里重新造一个太阳系，到时候想干什么就干什么了。”

花子疑惑道：“什么是太阳系？”狐神解释道：“就是围绕着太阳的星系，共有八大行星，而地球就是其中一个，也就是你生活的地方。”

花子点了点头：“原来是这样，那我们要怎么做呢？”

狐神回答道：“权限的话简单，你只要想着我就好了，至于怎么造，我可能要找一下母亲的阿卡西记录，再去一趟亚历山大图书馆了，至于现在嘛，我们先出去吧。”

说完，花子退出了空间，试着抛砖引玉，把她从里面弄出来。

狐神从空中被召唤出来，摔在地上：“嘿哟，我的屁股啊。”

“对不起，对不起，你没事吧？”

狐神摇摇头：“不疼，下次注意点。对了，能不能把那个雕像给放进去，那是我用来传送的媒介，这样的话，我就能在你的空间来去自如了。”

话音刚落，花子就把那个狐狸雕像给收入空间，随后想起一件事，回头道：“对了，忘记做自我介绍了，我叫花子，我还不知道你叫什么呢。”

狐神摸了摸她的头，微笑道：“八重樫神奈，叫我神奈就好了。”

花子回家睡大觉，等待某日神奈回归。

次日的花子来到藤原府做客，下女们共同地欢迎道：“欢迎花子小姐！”

“你们好，哈。”花子尴尬的回应着，她还是第一次见到这场面，一时令人猝不及防。

一股独特魅力的女性出现在花子面前，手中还有一把檀香材质的折扇，透露着自然香气，还写着她看不懂的中文。

“你好花子，我听我儿子提起过你，不然看样子，还以为你是哪家大小姐，中华有一句成语很适合你，叫什么来着，憨态可掬。”说着，收起了折扇，打趣着。

飒插口道：“母亲，你说成语她哪懂。”

藤原樱摆手微笑道：“罢了罢了，你们俩慢慢玩吧，客厅那边准备了点甜点，你们要是嘴馋就去吃吧。”

说完，扇着风走去书房，花子看着樱的身影，第一次感受到一位女性能有这般气质，像是令人憧憬的对象。

飒带着花子随便参观府邸，花子看到一间房间有着一套武士铠甲，刀架上有一把太刀以及打刀，刀柄和刀鞘的用料都是自己没见过的材质。

飒看了一眼房间，说：“怎么了？”

花子摇了摇头：“没什么，只是觉得那些刀用的丝绳很漂亮罢了。”

飒推开门，走进房间，拿着两把中最轻的打刀，递给花子：“给，可以试着近距离感受一下。”

花子接过打刀：“真的可以吗？”

飒点着头：“嗯，没关系的。”

花子感受着分量，沉甸甸的，眼睛看着柄，似乎令人有一种想拔刀的感觉。

花子看着飒，礼貌询问着：“我可以拔刀看看吗？”

“当然可以，不过请小心一点。”

花子用了些力气将刀拔出来，刀身有着一道道纹，就像水面激起的涟漪，似乎能想象出那种抽刀断水水更流，剑光瞬斩斩连竹的画面。

飒看着入神的花子，弯着剑指敲了一下她的额头说道：“这把刀，你感觉如何？”

花子羞涩的点了点头：“很很漂亮，我还是第一次见到这样的刀，花纹很特别。”

飒接过打刀，收回刀鞘，放回了原位，拉着花子的手说：“走吧，刚好快中午了，我们去吃饭吧。”

花子嗯了一声！

# 第三章 她

花子今日来到了神社山下，红绳连着一个又一个的鸟居，挂着一片又一片的红飘带，随风而动，也很少有人这么做，像是神奈的爱好，

——旧人连绳，新人挂；新人见风，识旧人。

走过一道又一道鸟居，突然一阵大风刮过，不远处的樱花漂在天空，一股卷风伴随着樱花围绕着花子。

她伸出了手，看着落在手上的樱花，又随风飘走，花子从未见过这种奇观，不禁露出微笑。

不过樱花随风漂浮罢了，只是卷风围身最可贵。

——风，花语与少女笑。

花子看着眼前的神社，神奈不在只有房檐的风铃轻轻作响，飘散了好多绿叶和樱花，贡品依然在那，不知道是谁供的，就像是每天长出来的一样。

想着来都来了，也不白吃，神奈不在家，帮她做个大扫除吧！

花子在神库里找扫帚，那里面有许多奇怪的东西，手摇铃，御币，还有许多雕刻的工具，找了半天才找到扫帚。

“看着不大，怎么这么难找？难道摆放有什么规律吗？”花子摇了摇头：“想不了那么多了，现在就开始吧！。”

刚打扫不久，来了一位源氏少女，看样子，像是某家小姐，穿着比自己好上不少。

少女跪拜在神社里，似乎在祈祷着什么，花子上前询问少女：“姐姐，你怎么了？狐神不在家，你可以跟我说，我会帮你转告她的。”

少女看向花子，又低下了头：“算了，我只是在这里等一个人罢了，不过祈求安慰，若有神，为什么我得不到眷顾。”

花子攥紧了扫帚，她不知道该怎么回答，只能看着对方焦虑的眼神。

花子叹了口气，接着去扫落叶，没过一会儿，来了一个身上溅血的剑客，直奔着少女。

少女抱着那位剑客，泣不成声，花子因为崩坏，听力要比以往要好，哪怕离得远一点也能听到他们在说什么。

那位剑客攥着她的手道：“已经没事了，不要哭了，女孩子还是要笑着好看。”

少女点了点头，顺带擦了下眼泪：“嗯，等了这么久，我们终于可以兑现了。”
