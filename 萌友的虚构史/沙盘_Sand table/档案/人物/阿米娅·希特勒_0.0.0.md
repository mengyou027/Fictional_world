# 个人简介

姓名：阿米娅·希特勒
别名：天选救世魔王，柏林最纯美的少女
性格：性格温和偶尔冷厉的魔王
身高/体重：175cm/50～65kg
性别：女
生日：2111年10月3日
国籍：美利坚，德意志
原型：人物原型是明日方舟的“阿米娅”，人物设定原型是《让子弹飞》的“张麻子”
作者：虚构史学家“萌友”
简述：被巨墙放逐没有价值的少女，是路西法最喜爱的女仆之一，被冠以纯美之名。
忘却了曾经在巨墙过往，在新地方激起涟漪；忘却了曾经在巨墙名字，被赐予阿米娅之名。
她比任何人都要优秀，觊觎她的人都死在了路西法的手下，直到那异乡客的到来。
以自由之身，见证各路乌托邦，戴上黑冠的那一刻起，以魔王之名，成为黑秩序的毁灭者。
——这个世界的荒诞，将迎来属于祂的终末。
