# 载具简介

载具名：大型环翼客机-GH_001-光环  
简名：光环  
别名：环天使  
定位：大型高速环翼客机  
初飞：暂定  
生产单位：河南光翼航空科技有限公司  
国属：秦汉人民共权国  
原型：环翼概念飞行器  
作者：虚构史学家“萌友”  
简述：这是光翼航空在黄月英众多遗稿中发现了一份环形战舰的图纸，这艘战舰拥有环绕舰体的环翼，拥有高效的空动性能，善于在星球作战，因为没有降落的需求，一般都在船坞停靠。  
他们以这艘战舰为参考，设计了适合陆地起降的客机，极速拥有0.8马赫（980km/h），非常合适跨国旅途，因为拥有环状机翼，被人们称为环天使这一称呼，并且拥有官方的虚拟形象。
