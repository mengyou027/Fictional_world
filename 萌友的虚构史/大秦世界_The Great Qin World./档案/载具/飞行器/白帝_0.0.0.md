# 载具简介

载具名：JQ-27
简名：白帝
别名：御空大小姐/空载杀手
定位：超高速超机动可变翼战斗攻击机（超速动可变翼机）
初战：时间未知
生产单位：长安超速星航空工业有限公司&上海飞星航空工业有限公司（360厂）
国属：秦汉人民共权国
原型：前掠翼原型“SU47”，机身原型“歼-20A”，主要原型“白帝空天战机”
简述：拥有三种模式的战斗攻击机，主要分为，均衡（后掠翼），机动（前掠翼）和超速（三角后掠翼）。
具备微型反重力引擎，减少星球引力带来的重力影响，拥有更先进的电离子推进器，极速达到了惊人的5.16马赫（6325km/h），具备机载核裂变，并且机身配有多处小型推进器，可以快速180度掉头回正，并使用空对空打击敌方，此等性能不是人类能承受的，属于智械驾驶的特种机。
