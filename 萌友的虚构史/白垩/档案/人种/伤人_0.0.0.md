# 种族简介

种族名：伤人
别名：狂人
原型：伤齿龙
种族特征：眼睛，夜视，听力等感官能力极强，比起棱人，更像鸟类的脚，退化了锋利的爪子（前三趾，后一趾），两颗心脏和发达的肺部，耐力属于人种顶峰，拥有极强的自愈能力，其他与人类无异。
极限身高：179cm
社会形态：军国兼资本式游牧社会形态，一个好战的民族，同时兼顾着经济与养殖，对盟友宽容，如果激怒他们，很难打好关系。
简述：棱人同化的第一个人种（伤齿龙），双方都有良好的外交关系，几乎是同时期开始进化的。
伤人是战争的狂热粉，偶尔跟部分种族进行经济交易，关系好还会剁下自己的一根手指送给对方，不到两三天的时间，就会完全长出新的手指。
没有强大的敌人，他们会选择强大的猎物，拥有强大的养殖能力作为经济交易，战时最强的盟友和平时最危险的盟友。
