# 总纲介绍

书名：沙盘/Sand table/サンドボックス
作者：虚构史学家“萌友”
主类型：乌托邦，反乌托邦，国家小说
副类型：双主角，超自然玄幻，超自然魔幻，科幻，末世，伪系统，架空世界，原生幻想
___

核心叙事：二十二世纪，人类资源枯竭，为争夺物资引发三战后，美洲建立巨墙隔绝世界，拥有大量资源，仍然向外掠夺。
巨墙内的资本启动了虚构幻想共产世界计划，巨墙内部的人民以为自己已经实现了共产，实际上是替换概念的资本构世主义。
巨墙外的国家们早已分崩离析，不同势力在曾经的国土上割据一方，建立各自的乌托邦。
外墙唯一的世界灯塔是中华人民与共和联邦。
外墙的人们从三战开始后就一直等在预言中的魔王，等待她的降临，摧毁一切虚构的秩序。

主题：来自外界的异乡客与本地的阿米娅相遇，共同探索与见证世界各地的乌托邦，待阿米娅戴上黑冠，以魔王之名，带领世界摧毁美利坚的巨构，重建世界新秩序。

基调：悲鸣，绝望，反抗，救赎，毁灭

主角：异乡客“千花万藏”与魔王“阿米娅”
