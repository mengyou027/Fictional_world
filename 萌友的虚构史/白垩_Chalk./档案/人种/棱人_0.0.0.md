# 种族简介

种族名：棱人
别名：始人种
原型：棱齿龙
种族特征：四个脚拇指，锯齿，腿部发达，有专门利用糖分的器官（像肝脏，但功能上跟肝脏不一样），其他与人类无异。
极限身高：197cm
社会形态：以母系为主的副共产主义形态，缺少道德，却以礼貌至上，在共产的基础上，各自都有各自的利益需求，天灾人祸难面前仍然会保持团结。
简述：从白垩纪到至今的初代智人种。
一名天外来客在白垩纪留下了甘蔗，直到一只棱齿龙吃掉一部分，部分在土壤中发芽，时往反复，棱齿龙学会了种植甘蔗，种下了智龙的进化方向，甚至同化了部分龙种。
因为甘蔗的原因，棱齿龙的大脑发达，部分时期进化成了像蜥蜴人类似的骨骼，最后才是我们所熟悉的人类，不仅如此，还与人类相差无几，但与正统人类有着生育隔离，相当于龙系和哺乳系的差距。
