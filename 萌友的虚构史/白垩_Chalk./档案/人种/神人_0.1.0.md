# 种族简介

种族名：神人
别名：羽美人
原型：灰烬黎明女神翼龙
种族特征：比自己大两倍多的羽翼，拥有支持音速飞行的眼膜，四只手指，两前趾和一后趾，身体器官有极强的抗G力能力，无外耳廓结构，拥有几乎纯美的颜值，其他与人类无异。
极限身高：62cm
社会形态：依存性奴隶社会形态，谁对他们好，他们就会跟随谁，拥有很强的学习能力和极高的情商，更像是一种依存性病娇，无论国家主义形态如何改变，也不会改变他们自愿为奴的习性。
简述：一开始被伤人作为宠物所养，后来是棱人采果的帮手。
但是他们的进化历程要比前者更艰难，相当于整个器官与骨骼重塑。
进化成人后，颜值就像是赐予他们的奖励，但与其他人种有生育隔离。
水平飞行大约325公里每小时，俯冲约400公里每小时。
