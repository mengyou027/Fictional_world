# 虚构世界

“虚构世界”是不同于以往的文学作品，也称之为虚构史或遗产，有诸多主角，在同一世界观下，讲述着不同国家、地区、时期的叙事。

比起小说、量大管饱，故事更聚焦于人物，而不是面向读者。但一个人写一个世界的能力是有限的，所以我们自发成为虚构史学家，共同撰写着虚构史或遗产。

我们没有组织，虚构史学会只作为交流平台存在，要保持自主性，远离包含任何意识形态的组织和交流平台。

如果你决定成为一个虚构史学家，那么请阅读虚构史学家黑皮书，了解我们的职责。

如果你擅长评论，社交，发掘，收集，或许可以成为虚构考古学家，那么请阅读虚构考古学家白皮书。

如果你想为虚构史或遗产进行译写，可自主成为虚构译史组，身份可以是虚构史学家，但我更推荐虚构考古学家。
