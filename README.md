# Fictional World

"Fictional World" is a literary work unlike any before, also referred to as fictional history or legacy. It features multiple protagonists and, within the same worldview, tells narratives from different countries, regions, and periods.

Unlike novels, which are abundant in content, these stories focus more on the characters rather than catering to the reader. But one person's capacity to write an entire world is limited, so we have spontaneously become fictional historians, jointly writing this fictional history or legacy.

We are not an organization; the Fictional History Society exists only as a communication platform. We must maintain autonomy and stay away from any organizations or communication platforms that carry any ideology.

If you decide to become a fictional historian, please read the Fictional Historian's Black Book to understand our duties.

If you excel at reviewing, socializing, discovering, and collecting, you might become a fictional archaeologist. Then please read the Fictional Archaeologist's White Book.

If you wish to translate or adapt fictional history or legacy, you may voluntarily join the Fictional Translation Group. Your identity can be a fictional historian, but I recommend being a fictional archaeologist.
